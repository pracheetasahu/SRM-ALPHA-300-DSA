

# Day 24 – Palindrome Depth

## Overview

Solved palindrome-based string problems by applying center expansion and manual character comparisons without using reverse slicing inside loops.

## Problems Completed

| No. | Problem | Approach |
|---|---|---|
| 1 | Longest Palindromic Substring | Center Expansion |
| 2 | Palindromic Substrings | Palindrome Counting |
| 3 | Shortest Palindrome | Two-Pointer Comparison |

## Concepts Practised

- Identifying odd-length and even-length palindromes.
- Expanding outward from center indices.
- Tracking the longest palindrome.
- Counting all palindromic substrings.
- Finding the longest palindromic prefix.
- Building a shortest palindrome.
