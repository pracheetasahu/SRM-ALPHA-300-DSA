# Day 18 – Sorting on Strings

## Overview

Practised string sorting problems using manually implemented sorting techniques without relying on Python's built-in sorting functions.

## Problems Completed

| No. | Problem | Technique |
|---|---|---|
| 1 | Sort Characters By Frequency | Frequency Counting, Merge Sort |
| 2 | Reorganize String | Greedy, Frequency Counting |
| 3 | Custom Sort String | Character Frequency, Custom Ordering |

## Concepts Practised

- Implementing merge sort manually.
- Sorting characters based on frequency.
- Reorganizing strings without adjacent duplicates.
- Maintaining character frequencies using dictionaries.
- Applying custom character ordering.
- Avoiding `sorted()` and `.sort()`.

- Python

## Learning Outcome

Improved string manipulation and sorting skills through custom sorting techniques, frequency counting, and greedy algorithms.
