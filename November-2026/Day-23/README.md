

# Day 23 – String Comparison Patterns

## Overview

Practised string comparison problems by traversing characters individually, tracking frequency differences, and identifying the minimum changes required to satisfy string conditions.

## Problems Completed

| No. | Problem | Technique |
|---|---|---|
| 1 | Determine if Two Strings Are Close | Frequency Counting |
| 2 | Minimum Changes to Make Alternating Binary String | Character Comparison |
| 3 | Check If One String Swap Can Make Strings Equal | Mismatch Tracking |

## Concepts Practised

- Comparing strings character by character.
- Tracking character frequencies using dictionaries.
- Comparing frequency distributions.
- Finding minimum changes for alternating patterns.
- Identifying mismatched character positions.
- Checking whether one swap can make strings equal.
