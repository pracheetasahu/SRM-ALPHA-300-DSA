

# Day 19 – Binary Search on Strings

## Overview

Practised string-based problems using binary search and string comparison techniques without using Python's built-in `bisect` module.

## Problems Completed

| No. | Problem | Technique |
|---|---|---|
| 1 | Find Smallest Letter Greater Than Target | Binary Search |
| 2 | Longest Word in Dictionary Through Deleting | Two Pointers, String Matching |
| 3 | Lexicographic Smaller String Comparison | Binary Search, Lexicographical Comparison |

## Concepts Practised

- Implementing binary search manually.
- Comparing strings lexicographically.
- Finding the smallest element greater than a target.
- Using two pointers for subsequence checking.
- Avoiding the built-in `bisect` module.

## Technology

- Python
- GitHub

## Learning Outcome

Improved understanding of binary search on strings, lexicographical ordering, and efficient string processing.
