

# Day 27 – Character Frequency + Sort Hybrid

## Overview

Practised character frequency and sorting problems by implementing custom merge sort and dictionary-based frequency counting without using Python's built-in sorting functions.

## Problems Completed

| No. | Problem | Technique |
|---|---|---|
| 1 | Sort Characters By Frequency | Frequency Counting, Merge Sort |
| 2 | Rearrange Characters to Make Target String | Frequency Counting |
| 3 | Reorganize String | Greedy, Frequency Sorting |

## Concepts Practised

- Counting character frequencies using dictionaries.
- Implementing merge sort manually.
- Sorting characters based on frequency.
- Calculating the maximum number of target strings.
- Rearranging characters without adjacent duplicates.
- Avoiding `sorted()` and `Counter.most_common()`.
