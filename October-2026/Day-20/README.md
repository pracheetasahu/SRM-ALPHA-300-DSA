
# Day 20 - Counting Sort

**Date:** October 20, Tuesday

## Problems Completed

### 1. Counting Sort
- Platform: GeeksforGeeks
- Problem: Counting Sort
- Link: https://www.geeksforgeeks.org/problems/counting-sort/1
- File: `counting_sort.py`
- Approach: Frequency counting using an array of size 26.
- Time Complexity: O(n)
- Space Complexity: O(1), excluding output.

### 2. Sort Colors
- Platform: LeetCode
- Problem: 75. Sort Colors
- Link: https://leetcode.com/problems/sort-colors/
- File: `sort_colors.py`
- Approach: Count the frequency of 0, 1 and 2, then overwrite the array.
- Time Complexity: O(n)
- Space Complexity: O(1)

### 3. Segregate 0s and 1s
- Platform: GeeksforGeeks
- Problem: Segregate 0s and 1s
- Link: https://www.geeksforgeeks.org/dsa/segregate-0s-and-1s-in-an-array-by-traversing-array-once/
- File: `sort_zeros_ones.py`
- Approach: Count zeros and rearrange the array.
- Time Complexity: O(n)
- Space Complexity: O(1)
